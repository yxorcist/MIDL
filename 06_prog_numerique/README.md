# Applications en ingénierie et programmation numérique

Organisation MIDL :

```text
CM/                         # séances chronologiques
TD/ficheNN/exercices/       # corrections par exercice
TP/tpNN/exercices/          # travail par exercice
```

Les sujets fournis par l'université ne sont pas recopiés dans le dépôt. MIDL conserve les notes et corrections produites à partir de ces supports.
