Privacy policy

Effective November 26, 2026.

MIDL is a personal, locally operated study tool. This policy describes its optional Google Drive integration.

Data accessed and purpose

When the user authorizes rclone to access Google Drive, the tool uses that authorization to locate folders and transfer files. Depending on the configured OAuth scope, access may include Drive file names, identifiers, metadata and content. The intended operations are synchronizing generated PDFs to MIDL/dist and moving user-selected incoming documents to MIDL/INBOX. Synchronization can delete destination files that no longer exist in the local source.

Storage and protection

Study files are stored on the user's computer and in the user's Google Drive account, as directed by the user. Rclone stores OAuth credentials in its local configuration. MIDL does not operate a hosted backend for collecting Google user data. Users should protect their local rclone configuration and must not commit credentials or private data to the public GitHub repository.

Sharing and use

MIDL does not sell Google user data, use it for advertising, or transfer it to a developer-operated server. The integration uses Google Drive and rclone to perform the requested file operations. Google and GitHub provide their own services under their respective privacy policies. MIDL does not use Google user data to train AI models.

MIDL's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention, deletion and revocation

Users control the retention and deletion of their files through their local file system and Google Drive. Users can revoke Google account access through Google Account connections and remove the local remote configuration using rclone. Revoking authorization does not itself delete previously transferred files.

Contact

For privacy questions, contact the repository maintainer through GitHub. Do not disclose credentials, private files or personal information in public issues.
