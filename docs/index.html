MIDL

MIDL is a personal, open-source study workflow that organizes university course material and generates PDFs from Typst sources on a local computer.

Google Drive integration

The optional Google Drive integration uses rclone to synchronize generated PDFs to the user's Google Drive and transfer incoming study documents into an INBOX folder. The user initiates and controls these transfers. Google Drive is not required for local builds.

MIDL is intended for personal use, not as a hosted service or public account-management platform.

For source code and setup instructions, visit the GitHub repository. For questions, contact the maintainer through the repository issue tracker. Do not post private information or credentials there.

Read the privacy policy for information about Google Drive access and data handling.
